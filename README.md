# Hi, I'm Daniel Wendisch

Physician-scientist working on **human immunology and genetic variation**. I'm a postdoc in John Tsang's lab at Yale (Center for Systems and Engineering Immunology), where I study how allelic expression changes over time. Before that I worked on macrophage responses in severe viral infection and lung fibrosis, at Charité and the Berlin Institute of Health.
